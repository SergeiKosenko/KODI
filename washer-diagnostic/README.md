# МастерКод — Android-справочник мастера

Рабочая тестовая версия для диагностики стиральных машин по кодам ошибок. Интерфейс на русском языке, офлайн-каталог, планы проверок, избранное, заметки, история карточек, сервисные инструкции и расширение базы через JSON.

## Готовые материалы

- `dist/mastercode-0.1.0-debug.apk` — APK для Android 8.0+ (API 26) с актуальным Android System WebView, target API 35.
- `dist/mastercode-presentation.pdf` — презентация для мастеров, 10 слайдов.
- `dist/mastercode-source.zip` — исходники, документация и тесты, без Android SDK и ключей подписи.

APK подписан **отладочным ключом**, подходит для тестовой установки. Для выпуска нужен собственный release-ключ и отдельное тестирование Android-оболочки. Установить APK можно открытием файла на телефоне либо командой `adb install -r dist/mastercode-0.1.0-debug.apk`, если Android Platform Tools установлены. На телефоне или эмуляторе APK в этой среде не запускался.

## Реальный объём каталога

- 40 марок в указателе, **не 40 полностью поддержанных модельных рядов**.
- 79 справочных карточек ошибок для 15 марок: Samsung, LG, Bosch, Siemens, Indesit, Hotpoint-Ariston, Beko, Candy, Electrolux, Zanussi, AEG, Whirlpool, Atlant, Haier, Gorenje.
- 1 черновой сценарий входа в проверочный режим для LG F1096ND3 / F1296ND3, с обязательной сверкой панели и документации специалистом. Таблица отдельных тестовых этапов не включена.
- Полной базы всех моделей, используемых в России, нет. Идентичный код у разных серий может иметь другой смысл. Пользовательский ввод модели не превращает общую справочную карточку в инструкцию для этой модели.

Штатные сведения составлены из общих знаний, **не подтверждены первичными сервисными документами** и имеют статус `reference`. Документация производителей не загружена. Проверка доступа к Samsung Support вернула отказ сетевой политики; это не было обойдено. Интернет-источники и соответствие кодов каждой модели не проверены. Для профессионального применения нужно собрать и проверить документацию по полным моделям, кодам изделий и ревизиям электроники.

Сервисный режим может запускать вращение, набор воды и нагрев. Приложение предназначено для специалистов; оно не измеряет электрические параметры и не управляет машиной. Не обходите блокировки и защиту. Перед внутренним осмотром отключайте питание; измерения под напряжением — только по сервисной методике и с необходимым допуском.

## Сборка APK без Gradle

Требуются Linux x86_64, Java 21 с модулями `jdk.compiler` и `jdk.jartool`, `keytool`, Python 3, curl и sha1sum. Сторонних Java/JavaScript-библиотек у приложения нет.

```bash
cd /workspace/-/washer-diagnostic
./scripts/install-sdk.sh
./scripts/build-apk.sh
```

`install-sdk.sh` загружает Android Platform 35 и Build Tools 35.0.0 с `dl.google.com`, проверяет опубликованные Google контрольные суммы и распаковывает SDK в `.android-sdk/`. TLS-проверка включена. При использовании Android SDK действуют условия лицензии Google из SDK-архивов. SHA-1 используется как формат контрольных сумм, опубликованных репозиторием Android; не заменяет TLS.

Для уже установленного SDK:

```bash
ANDROID_SDK_ROOT=/workspace/android-sdk ./scripts/build-apk.sh
```

Скрипт рассчитан на структуру этих официальных архивов (`android-15/` для build tools, `android-35/` для платформы). Генерирует ресурсы через `aapt2`, компилирует Java, создаёт DEX через D8, выравнивает APK, подписывает и проверяет подпись. Ключ разработки хранится только в игнорируемом `build/debug.keystore`. Не используйте его для публикации. На новом ключе APK не обновит установленную сборку с другим ключом: сначала сохраните резервную копию, затем переустановите приложение.

## Запуск интерфейса в браузере

```bash
cd app/src/main/assets
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте локальный сервер в браузере. Открытие HTML через `file://` не поддерживается из-за загрузки JSON. Браузерная версия служит для разработки; установочное Android-приложение работает без сервера.

## Проверки

```bash
node tests/core.test.cjs
node tests/browser.test.cjs
```

Второй тест требует запущенный сервер на порту 8765, Chromium `/usr/bin/chromium` и Playwright для Node. Это зависимости инструментов разработки, а не приложения. В данной среде они уже доступны.

Проверено:

- 7 тестов логики: нормализация кода, разделение марок, точная модель сервисной инструкции, валидация и происхождение импортируемых данных, запрет опасных URL, уникальность карточек.
- Сценарии Chromium: поиск, избранное, заметки после перезагрузки, сервисная инструкция и её скрытие для другой модели, ошибочный и корректный импорт, точное ограничение модели в импортированной карточке, экспорт и восстановление резервной копии.
- Мобильный экран 390×844, отсутствие переполнения по ширине, открытие/закрытие карточки; ошибок JavaScript не обнаружено.
- APK: компиляция, подпись v2/v3, манифест и минимальная версия Android.

Не проверены: установка и работа Android WebView/системных файловых диалогов на реальном устройстве или эмуляторе; корректность диагностики на реальных машинах; все ветки чернового сервисного сценария. Прохождение программных тестов не подтверждает технические сведения каталога.

## Данные и приватность

У APK нет разрешений INTERNET и доступа к общему хранилищу. Интерфейс обслуживается локальным перехватчиком ресурсов WebView; внешние ссылки открываются в системном браузере. JSON выбирается/сохраняется через системный Storage Access Framework. Записи базы, заметки, избранное и история находятся в локальном хранилище WebView. Нет серверной части, аккаунтов, аналитики и рекламы.

Удаление приложения удаляет локальные данные. Делайте экспорт из «Каталог и база». Резервная копия включает импортированную базу, заметки и избранное; история открытых карточек не экспортируется. Штатный каталог восстанавливается из установленного приложения. Экспорт может содержать личные заметки. Не храните в них платёжные данные и пароли.

## Расширение базы

См. `docs/DATA_FORMAT.md`. Импорт ограничен 5 МБ / 3000 записей; каждое описание должно иметь источник (`title`, HTTPS `url`, `page`). Для процедуры обязательны точные модели, подготовка, шаги и выход. Все импортированные сведения получают статус `imported`: приложение не проверяет достоверность источника автоматически. Запись с одинаковым `id` обновляет существующую. Отмена или ошибка валидации не заменяет текущую базу.

## Презентация

```bash
node scripts/capture-screens.cjs  # при запущенном локальном сервере
python3 scripts/create-presentation.py
```

Нужны Python ReportLab, Pillow и шрифты DejaVu Sans. Скриншоты для остальных слайдов создаёт браузерный тест. PDF содержит реальные экраны веб-интерфейса, а не снимки с физического Android-устройства.

Исходные учебные файлы в корне репозитория сохранены без изменений. Проект не связан с производителями и не является официальной сервисной документацией.
